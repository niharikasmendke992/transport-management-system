# 🚚 Transport Management System

## Overview

Transport Management System is a MERN Stack-based web application designed to streamline logistics and transportation operations. The system provides a centralized dashboard for managing vehicles, routes, and transport-related activities.

## Features

* Vehicle Management
* Route Monitoring
* Logistics Dashboard
* Status Tracking (Active, Delayed, Pending)
* Search Functionality
* Responsive User Interface

## Tech Stack

### Frontend

* React.js
* JavaScript
* CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB
